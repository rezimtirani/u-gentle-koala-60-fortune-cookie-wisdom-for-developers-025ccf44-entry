One original fortune-cookie line for a software developer, entered in the
[make.fun](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44)
bounty "Fortune Cookie Wisdom for Developers".

## The fortune

> The maintainer you keep apologizing to is your future self.

59 characters, one line — inside the competition gate of 1 to 120 characters.

## How it works

`main.py` validates the line against the gate (UTF-8, 1–120 characters,
single line, not blank) and writes it to `/output/entry.txt`:

```sh
python3 main.py
```
